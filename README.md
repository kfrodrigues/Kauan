# Truco do Cec

Site do truco da galera: ranking de vitórias, placar de tentos, tabela de força (mineiro e paulista), sinais do rosto e os jogadores (Kauan, Miguel, Thiago, Grael e Pedrão) com avatares engraçados — dá para colocar a foto de cada um.

- `src/truco.html` — código da página
- `index.html` — página completa gerada por `./build.sh` (abra no navegador ou publique no GitHub Pages)

Fora do claude.ai os resultados ficam salvos no navegador de quem abriu.
