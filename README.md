# Truco do Cec

Site do truco da galera: ranking de duplas (jogadores e duplas), ranking individual com jogo ao vivo de 3 vidas, placar de tentos, tabela de força (mineiro e paulista), sinais do rosto e os jogadores (Kauan, Miguel, Thiago, Grael e Pedrão) com avatares engraçados — dá para colocar a foto de cada um.

- `src/truco.html` — código da página
- `index.html` — página completa gerada por `./build.sh` (abra no navegador ou publique no GitHub Pages)

Fora do claude.ai os resultados ficam salvos no navegador de quem abriu.

# Minha Obra

App para controlar gastos e andamento da construção da casa: painel com totais e gráficos, lançamentos com foto do recibo, etapas com orçamento e % concluída, fornecedores com WhatsApp e comparador de preço, contratos parcelados, diário com fotos e exportação para Excel/CSV.

- `minha-obra/minha-obra.html` — código da página, publicada como artifact no claude.ai (os dados ficam no banco compartilhado do artifact)
